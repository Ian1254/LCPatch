# LCPatch 1.2.4-test.2 — Shizuku 背景套用測試

這是獨立測試分支，非正式發布版本。不建立版本 Tag 或 GitHub Release。

## 變更

- Shizuku 模式下載後只選擇漢化包；統一從概觀啟動遊戲並建立待套用通知，不提前修改語言檔。
- 在遊戲標題畫面拉下通知欄，點「套用漢化」；通知將 LCPatch 切到前景後直接啟動寫入，不必手動找 App 或切到已下載頁面。
- Shizuku UserService 確認遊戲程序仍存在，直接逐檔更新同名 JP/KR JSON，不交換整個語言目錄。
- Android dataSync 前景服務維持工作；通知顯示真實已寫入檔案數、總數與完成／失敗結果。
- 保留原始語言目錄完整備份，支援舊版手動還原；不監控遊戲退出，也不自動還原。
- 只改無 Root Shizuku 寫入流程，不改 Root 原生核心。

## 裝置測試步驟

1. 如之前曾透過 1.2.3 套用原生漢化，先手動停用，完成還原。
2. 啟動 Shizuku，授權 LCPatch，授予通知權限。
3. 在 LCPatch 選擇「無 Root → Shizuku」，點「下載並選擇」（已有漢化包可從已下載頁點「選擇」），再回概觀點「啟動遊戲」。系統通知若關閉，請先授權通知。
4. 遊戲自動開啟，以原始資源完成下載與一次性驗證，等標題畫面正常顯示。
5. 直接拉下通知欄點「套用漢化」。LCPatch 會取得前景焦點，原本遊戲仍保留在背景。
6. 監看通知欄的實際寫入進度與完成／失敗結果。
7. 從最近使用的 App 切回原本的遊戲程序，確認文字。
8. 想還原時使用 LCPatch「停用漢化」，這會停止遊戲並還原備份。

## 已知限制

- **遊戲退出不會自動還原**。概觀的「啟動遊戲」會檢查是否仍保留舊漢化備份；如果有，要求先手動停用並還原，避免重新驗證失敗。這個限制來自使用者選擇不自動還原。
- 沒有可靠機制確認 Unity 遊戲已完成一次性驗證；不使用固定延遲或檔案下載完成來假裝等同驗證完成。通知請在資源下載完、標題畫面已正常顯示時手動點一次。
- Shizuku 的 shell 身份是否能寫入 Android/data 因裝置／系統而異。權限已授權不代表具備寫入權限。
- 同語言允許重複套用，沿用第一次套用前的備份。在遊戲**仍運行**的情況下，可從「已下載漢化」使用「重新套用」直接寫入；切換 JP/KR 仍必須先手動還原。
- 既有 1.2.3 備份會先驗證原始文件完整性，不盲目覆蓋。
- 這個版本仍需實機驗證。CI 單元測試和編譯通過不代表所有遊戲版本或裝置相容。
- 無 Root 的網路資源替換仍在可行性研究，尚未內建。詳見 docs/rootless-network-feasibility.md。
- Android 13+ 需要通知權限；首次拒絕後，應在系統設定授權再開始測試。準備通知並非持續執行中的前景服務，真正寫入才啟動 dataSync 前景服務。
