# LCPatch 1.2.4-test.1 — Shizuku 背景套用測試

這是獨立測試分支，非正式發布版本。不建立版本 Tag 或 GitHub Release。

## 變更

- Shizuku 模式下載漢化後只保留資源，不再自動關閉遊戲並套用。
- 在遊戲標題畫面按 Home 切回 LCPatch，從「已下載漢化」啟動背景套用。
- Shizuku UserService 確認遊戲程序仍存在，直接逐檔更新同名 JP/KR JSON，不交換整個語言目錄。
- Android dataSync 前景服務維持工作；通知顯示真實已寫入檔案數、總數與完成／失敗結果。
- 保留原始語言目錄完整備份，支援舊版手動還原；不監控遊戲退出，也不自動還原。
- 只改無 Root Shizuku 寫入流程，不改 Root 原生核心。

## 裝置測試步驟

1. 如之前曾透過 1.2.3 套用原生漢化，先手動停用，完成還原。
2. 啟動 Shizuku，授權 LCPatch，授予通知權限。
3. 在 LCPatch 選擇「無 Root → Shizuku」，下載符合已安裝遊戲版本的原生語言包。
4. 以原始語言文件啟動遊戲，在標題畫面完成資源下載／驗證。
5. 按 Home，保留遊戲任務，不要划掉或重新啟動。
6. 回 LCPatch → 已下載漢化 → 套用，確認通知欄顯示已處理檔案數與完成通知。
7. 從最近使用的 App 切回原本的遊戲程序，確認對應文本。
8. 想還原時使用 LCPatch「停用漢化」，這會停止遊戲並還原備份。

## 已知限制

- **遊戲退出不會自動還原**。下一次啟動若重新驗證已修改的 JSON，可能需要先手動還原，再按背景套用流程操作。
- Shizuku 的 shell 身份是否能寫入 Android/data 因裝置／系統而異。權限已授權不代表具備寫入權限。
- 同語言允許重複套用，沿用第一次套用前的備份；切換 JP/KR 仍必須先手動還原。
- 既有 1.2.3 備份會先驗證原始文件完整性，不盲目覆蓋。
- 這個版本仍需實機驗證。CI 單元測試和編譯通過不代表所有遊戲版本或裝置相容。
- 無 Root 的網路資源替換仍在可行性研究，尚未內建。詳見 docs/rootless-network-feasibility.md。
- 前景通知需 Android 13+ 的通知權限，拒絕後應在 App 中重新授權再開始測試。
