# LCPatch 1.2.4-test.3 — 直接套用與漢化包管理

這是測試分支，僅由 Actions 簽章並產生測試 APK；不建立 Tag、不發布 GitHub Release。

## 操作

- 下載完成直接套用，不需先選擇漢化包再回概觀操作。
- 已下載頁的名稱與版本在左，緊湊的「套用／重新套用」按鈕在右；Root 與無 Root 共用同一張卡片。
- 頁面右上角垃圾桶進入批量刪除，支援全選／取消全選、返回取消，以及執行前一次確認。僅移除下載內容；部分失敗會保留失敗項目，方便重試。
- 移除漢化包匯出 ZIP、原始語言備份與還原功能。舊備份目錄不參與新流程，也不會阻擋重套或切換語言。
- Shizuku 寫入不強制關閉遊戲，逐檔寫入並顯示真實進度。套用失敗不交換整個語言目錄。
- 概觀的啟動遊戲可建立待套用通知；遊戲進入標題畫面後，點擊整張通知即可套用。通知不含獨立動作按鈕。
- 刪除設定頁整行「文件載入設定」，載入方式選擇與授權集中於概觀「文件載入方式」。
- 放大並加粗 LCPatch、日誌、設定三個主頁標題。

## 版本辨識

- 保存下載來源的 Release 標籤；支援 Android 字形漢化來源與官方 PC 來源。
- 匯入時讀取包內版本清單；舊包可從保存的來源網址推斷標籤。
- 舊無 Root 包缺少版本資訊時，以完整 SHA-256 文字資源指紋比對當前來源；只有完全符合才回填來源版本。比對來源下載後會校驗 GitHub 提供的資產摘要，並快取結果。
- 對不上已知來源的包顯示內容識別碼，不使用下載日期或現在最新的版本冒充來源版本。
- 「已套用」同時比對包身分與版本；同名包更新後不會沿用舊的選中狀態。

## 驗證

不執行裝置／模擬器測試，由使用者下載測試。執行 JVM 回歸測試、Release 建構、lint 與 Compose 預覽；測試包含不備份／不還原、舊備份不阻擋寫入、來源版本與內容識別。
